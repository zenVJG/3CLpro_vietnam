# 3CLpro_vietnam
some codes I used for the project ( exclude R since it's to random, might update later)
1. ID_extract.py used for extracting GISAID ID in the BLAST format 6
2. extract_918nt.py takes only the CDS of 3CLpro with sequences compare to RefSeq
3. filter_undefined_char.py removes unrecognizable characters included sequences in gene and protein
4. mutation_stats.py turns mutation datas in the BLAST format 6 to a statistical list
5. nxn_mutiple.py docks n proteins with n ligands, with n runs (as you like)
